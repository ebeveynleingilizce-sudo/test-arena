# TEST ARENA — UI / UX DESIGN SYSTEM

## Ana Görsel Referans

Uygulamanın onaylanmış ana görsel referansı:

design-reference/test-arena-master.png

Bu dosya UI geliştirilmeden önce mutlaka incelenmelidir.

Görsel referans yalnızca ilham değildir.

Uygulamanın:

- görsel yoğunluğu
- renk dengesi
- kart yapıları
- boşluk kullanımı
- mobil ekran kompozisyonu
- tipografi hiyerarşisi
- arena atmosferi
- buton oranları

için temel referanstır.

Görsel arka plan resmi olarak kullanılmamalıdır.

Arayüz gerçek HTML/CSS bileşenleriyle oluşturulmalıdır.

---

# Tasarım Karakteri

Test Arena:

- modern
- enerjik
- rekabetçi
- sıcak
- oyunlaştırılmış
- temiz

görünmelidir.

Ancak çocukça görünmemelidir.

Uygulama 2. sınıftan 12. sınıfa kadar kullanılacaktır.

7 yaşındaki öğrencinin ilgisini çekmeli fakat 17 yaşındaki öğrenciye çocuk uygulaması hissi vermemelidir.

# Ana Renk Yönü

Temel marka ilişkisi:

DERİN LACİVERT + TURUNCU / ALTIN

Destek:

SICAK KREM / KIRIK BEYAZ

Lacivert güven ve premium hissi verir.

Turuncu:

- enerji
- XP
- hareket
- CTA
- yarış

için kullanılır.

Altın:

- yıldız
- başarı
- yüksek sıra
- ödül

için kullanılabilir.

---

# Kaçınılacak Renkler

Ana marka rengi olarak klasik parlak teknoloji mavisi kullanılmamalıdır.

Özellikle Windows / Microsoft tarzı yoğun mavi arayüz istenmemektedir.

Rastgele pastel renkler kullanılmamalıdır.

Her bölüm kendi bağımsız renk temasına sahipmiş gibi görünmemelidir.

Renk sistemi bütün uygulamada tutarlı olmalıdır.

---

# Durum Renkleri

Yeşil:

yalnızca başarı / doğru cevap gibi durumlarda.

Kırmızı / mercan:

yalnızca yanlış cevap / hata / tehlikeli işlem durumlarında.

Bu renkler ana marka renkleri değildir.

# Kartlar

Her bilgi ayrı beyaz karta konulmamalıdır.

Arayüz "dashboard template" veya "kart yığını" gibi görünmemelidir.

Kartlarda:

- sıcak açık yüzey
- yumuşak radius
- çok hafif border/gölge

kullanılabilir.

# Minecraft

Minecraft veya pixel-art Test Arena'nın ana görsel dili değildir.

Minecraft benzeri karakter/parkur özellikleri ileride ayrı ödül/tema sistemi olarak değerlendirilebilir.

Ana uygulama UI'si Minecraft arayüzü gibi görünmemelidir.

# Duolingo

Duolingo birebir kopyalanmamalıdır.

Özellikle:

- Duolingo yeşili
- Duolingo öğrenme yolu
- buton şekillerinin birebir taklidi
- maskot yaklaşımının kopyalanması
- aynı ekran kompozisyonları

kullanılmamalıdır.

Duolingo'dan yalnızca şu ürün prensipleri öğrenilebilir:

- hızlı geri bildirim
- düşük kullanım sürtünmesi
- sade navigasyon
- motivasyon
- oyunlaştırma

Test Arena'nın kendi kimliği korunmalıdır.

---
